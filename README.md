# Snowflake

Snowflake is a censorship-evasion pluggable transport using WebRTC, inspired by Flashproxy.

This is an unofficial repository representing Tor Project's Snowflake project
with modifications and improvements added to the original code.

The original Tor Project's README.md can be found here: [README.TP.md](README.TP.md)
